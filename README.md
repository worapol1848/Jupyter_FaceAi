# Face Classification Dataset (AI Workshop)

ชุดข้อมูลรูปภาพใบหน้าสำหรับการฝึกฝนโมเดลปัญญาประดิษฐ์ (AI) เพื่อจำแนกประเภทลักษณะใบหน้า โดยแบ่งออกเป็น 2 ประเภทหลัก

## โครงสร้างข้อมูล
ชุดข้อมูลถูกแบ่งออกเป็นโฟลเดอร์ตามประเภทของข้อมูล (Labeled Folders):
- **Funny Face**: รวบรวมรูปภาพใบหน้าที่มีลักษณะตลกหรือมีการแสดงออกที่ผิดแผกไปจากปกติ
- **Normal Face**: รวบรวมรูปภาพใบหน้าในลักษณะปกติหรือการแสดงออกทั่วไป

## รายละเอียดทางเทคนิค
- **ประเภทไฟล์**: รูปภาพ (.jpg)
- **วัตถุประสงค์**: ใช้สำหรับการทำ Image Classification หรือ Image Recognition Workshop
- **จำนวนข้อมูล**: รวบรวมรูปภาพจากการถ่ายภาพจริงและรูปภาพจากแอปพลิเคชัน LINE

## วิธีการใช้งาน
สามารถนำชุดข้อมูลนี้ไปใช้ร่วมกับไลบรารีสำหรับการทำ Deep Learning เช่น:
- TensorFlow / Keras
- PyTorch
- OpenCV (สำหรับงาน Image Processing เบื้องต้น)

โดยใช้โครงสร้างโฟลเดอร์เป็นตัวกำหนด Label (ImageDataGenerator ใน Keras หรือ ImageFolder ใน PyTorch)
